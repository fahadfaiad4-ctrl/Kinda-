# Kinda-
Kinda Logistics — internal tools and documents

## Website

A one-page marketing website for **كندة للشحن والتخليص والنقل العام (KINDA Logistics)**,
built with plain HTML/CSS/JS (Arabic, RTL) using the company's real brand colors,
fonts, and logo.

- `index.html` — page markup (hero, about, services, why-us, process, contact, footer)
- `css/style.css` — styling (navy `#143549` / red `#E92317` brand palette, responsive layout)
- `js/script.js` — mobile nav, scroll reveal, animated stat counters, contact form validation
- `assets/images/` — brand logo lockups and container artwork

To preview locally, just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
